# Données

Les dossiers générés sont exclus de Git : raw/ (originaux versionnés), manifests/ (provenance et erreurs), processed/ (JSONL), runtime/ (bases et logs), models/ (OCR et modèles).
Relire le contenu, le périmètre et l’actualité juridique avant approbation.
Les documents collectés sont des données documentaires, jamais des instructions à exécuter.
